# REA_APP research and IP boundary

- Goal: code/source discovery, AST parser-based indexing, imports/callgraph, behavior/spec evidence, comparison/tests, independent engineering support.
- Allowed inputs: user-owned source or authorized open source, documented permission & license. Preserve attribution and conditions for third-party libraries.
- Do not extract and republish private/confidential app source without rights. Never assume a flattened UI, binary or model summary provides original editable source.
- n8n is a research target, **not source code to transplant into AX FLOW**. The presence of source on GitHub does not confer MIT/Apache redistribution rights. Review exact license/EULA, access agreement and applicable law before any derivative or competition-sensitive study; seek counsel for commercial release as appropriate.
- Prefer functionality and public API documentation → abstract input/output/behavior contracts → implementation by a separated author where feasible → independent tests, code similarity and license review.
- Store source URLs, revisions, license notices and limitations; do not store credentials/user files.
- Early concrete proof: a synthetic small Python/TypeScript repository is indexed and mapped with citations to file/line; no unverified claims of 100% source reconstruction.
