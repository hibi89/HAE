# 개인 소버린 AI — FrontierOR Challenge 2027 실전 검증 목표

> OWNER PLAN / 2026-10-29 KST. **장기 연구·대회 도전 목표 기록. 개발 착수·등록·입상·예선 통과 사실 아님.**
> **명칭 정정:** 본 프로젝트는 별도 이름 미확정인 **독립형 개인 소버린 AI**이다. 기존 AI 시스템 역공학을 뜻하는 **REA_AI (Reverse Engineering Anything - AI)** 와는 **다른 프로젝트**다. REA_AI를 새 로컬 AI의 제품명·기술 엔진으로 오인하지 않는다.

## 1. 대회

- 대회: [FrontierOR Challenge 2027](https://frontieror-challenge.com/) — AI agentic operations research / optimization.
- 공식 예선 일정(2026-10-29 확인): **2027-01-04 ~ 2027-02-01**, 4주 × 15문제 = 총 **60문제**, 각 라운드 7일.
- 결선 시작 안내: **2027-02-08**, 세부 규정은 별도 공지 예정.
- **예선 통과 팀 수·커트라인 현재 미확정.** 60문제 유효해 생성은 자동 통과 조건이 아님. 점수는 숨겨진 인스턴스에서 제약조건 만족 및 최적화된 목적함수의 상대 점수로 산출.
- 공식 연습 문제: [Testing stage 문제 6종](https://frontieror-challenge.com/problems). 연습 점수는 예선 성적에 미반영.
- [공식 규정](https://frontieror-challenge.com/docs), [Main 평가/채점](https://frontieror-challenge.com/docs/main/scoring).
- **Main 트랙:** 공개 OSS 의존성, **2 vCPU / RAM 4GB / 네트워크 없음**, 제한시간 내 숨겨진 입력에 대응하는 독립 실행 솔버 제출. **Self-hosted:** 개인 장비에서 실행 후 솔루션 제출, 별도 리더보드. 트랙 변경은 Stage 1 시작 전에만 가능한 것으로 안내됨.

## 2. 사용자 목표

**2027년 1월 FrontierOR를, 개인이 만든 독립 소버린 AI의 첫 실전 OR 검증 무대로 삼는다.** 목표는 '참가만'이 아니라 **검증 가능한 솔버 성능**과 **결선 진출 도전**. 다만 실제 성적이나 통과 가능성은 연습·비공개 문제 성과 전까지 예측할 근거 부족.

장기 연구 가설: 경량 로컬 Qwen(문제 이해/전략) + CPU 알고리즘 및 병렬 탐색 + 작은 ML 탐색 정책 + **Lightning Azent(LA) 작업 플로우** + 독립 검증·피드백으로, 단독 LLM 또는 기준 솔버에 비해 동일한 정확성에서 연산비용·시간을 줄일 수 있는가.

이 구조는 연구 설계이고 **현재 미개발·미검증**. 실제 지원 기능은 원격 HEAD·코드·테스트를 확인하기 전까지 완료로 주장하지 않는다.

## 3. 대회용 시스템 역할과 의존 조건

1. **LA 선행:** 기존 HAE↔LA 제품 요구를 먼저 완성하고 검증한다. 분기/합류, 작업 예산, 재시도·상태, 결과/검증 이력 등은 LA의 실제 지원 여부부터 확인한다.
2. **문제 이해:** 로컬 Qwen 또는 동등 모델이 공개 문제의 목표·변수·제약 후보·입출력 스키마를 구조화. LLM의 해석만으로 가능한 정답을 임의 제거하지 않는다.
3. **문제별 솔버 설계:** 제약조건에 맞는 결정론적 알고리즘/휴리스틱/기존 허용 OSS 솔버를 기본선으로 구성하고, 동적 분할·ML 배분은 **동일 조건에서 이득이 확인될 때만** 추가.
4. **자동 검증:** 공식 검사기와 공인 가능한 제약 검사로 유효성을 먼저 증명하고, 목적함수 품질을 측정. 여러 유형·새 인스턴스를 테스트해 과적합을 방지.
5. **Main 트랙 실전:** **GPU/Qwen/LA가 솔버 개발·탐색 준비를 지원하더라도**, 최종 제출된 Python 솔버는 **2 vCPU·4GB·오프라인·해당 시간 제한** 환경에서 독립 실행되도록 설계. 모든 내부 에이전트 소스가 자동으로 비공개 유지된다고 가정하지 않는다.
6. **데이터/권리:** 대회 공개 문제·라이선스·제출 규정 준수; 타인의 비공개 테스트 문제 및 주최 측 서버에 무단 접근 금지.

## 5. 합격 게이트 및 실패 시 fallback

- **G1 / 연구 초기 성공:** 공개 연습 문제 6종 모두 각 문제의 규칙에 맞는 **유효한 해를 한 번 이상 생성**. 연습 문제와 비공개 문제는 난도가 달라 일반화 보증 아님.
- **G2 / 성능 입증:** 동등 제약·환경에서 기준 알고리즘보다 동등 정확도 혹은 더 좋은 목적함수 값, 그리고 전체 시간/비용 개선을 반복 실험으로 확인. 둘 중 하나만 좋으면 그 사실 그대로 기록.
- **G3 / 대회 준비 완료:** 공식 Main 제출 계약·메모리·시간·오프라인 테스트 재현; 주최 측 제출 시 실제 성공 영수증 확인.
- **G4 / 예선 통과:** 공식 발표로만 인정; **60문제 전부 유효하더라도 자동 통과 아니다.**
- **Fallback:** 탐색 ML 정책이 성능을 해치면 검증된 고전 OR 알고리즘/OR-Tools 등 허용되는 오픈소스 기준 솔버를 활용한다. AI 서사를 위해 더 나쁜 솔버를 제출하지 않는다.

## 6. 프로젝트 경계와 다음 결정

- **별도 소버린 AI 이름 미정.** REA_AI 이름 재활용 금지; 기존 REA_AI는 AI 역공학용 기술 연구로 구분한다.
- 2026년 기존 세 해커톤 코드/브랜치/공식 제출 내용은 변경하지 않는다. 대회 출전도 아직 미등록이며 개발 예산/유료 인프라/계정 접근을 이번 문서가 승인하지 않는다.
- 사용자가 명시적으로 지시하기 전에는 새로운 제품 레포/솔버 코드/유료 API/외부 제출을 자동 생성하지 않는다.
- 공개 해총 상황실에는 이 도전 목표의 **개요만 보관**한다. 상세 연구 기술은 이 PRIVATE 원본에 보존한다.
